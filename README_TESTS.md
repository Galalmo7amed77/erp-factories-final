# الاختبارات

الملفات تُشغَّل في SQL Editor بمشروع Supabase، وكل اختبار يعمل داخل transaction تُلغى بعدها كل البيانات.
النتيجة تظهر كخطأ يحمل التقرير (هذا مقصود، لأنه يضمن التراجع عن كل التغييرات).

- `01_permissions_suite.sql`: اختبارات الصلاحيات والعزل والحساب والاعتماد والنقل والحماية (التقرير النهائي 99 من 100 في الجولة الثانية، مع تصحيح توقع P06 بعدها).
- `02_adjustments_attendance_suite.sql`: المكافآت والجزاءات، والحضور بأكثر من وردية، وحضور الإدارة (20 من 20).

المعرّفات الثابتة في الملفات تخص الحسابات الحالية. عند إنشاء قاعدة جديدة، استبدلها بمعرّفات الحسابات الجديدة.
